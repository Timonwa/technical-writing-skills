# Terminology list and glossary — templates

## Terminology list

For the writers: one row per concept, alphabetical by term. A cell with no answer yet stays, left blank. **Translate** feeds `localization`'s do-not-translate list.

```markdown
# <Docs set> terminology

| Field         | Answer       |
| ------------- | ------------ |
| Owner         |              |
| Last reviewed | <YYYY-MM-DD> |

| Term | Definition | Use | Don't use | Translate | Notes | Decided |
| ---- | ---------- | --- | --------- | --------- | ----- | ------- |
| <exact form> | <one plain sentence, understandable alone> | <part of speech, capitalization, irregular forms> | <variants seen in the wild> | <yes · never> | <where it appears, what it's confused with, when to link the glossary> | <YYYY-MM-DD> |
```

## Glossary

For readers: a real page, alphabetical and one level deep. Each entry defines the term without using it, without leaning on other glossary terms, and links the page that explains it properly.

```markdown
# Glossary

## <Term>

<One or two plain sentences.> [Learn more about <term>](<link to the page that explains it>).
```
