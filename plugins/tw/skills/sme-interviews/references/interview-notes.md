# Interview notes — template

One file per session, named `<yyyy-mm-dd>-<name>.md`, kept where the project keeps its docs working notes or handed back in the conversation. Every field and section is present; one with no answer yet stays, left blank.

```markdown

| Session         | <live interview · screen-share · written question list · technical review>         |
| Time booked     | <minutes>                                                                          |
```
