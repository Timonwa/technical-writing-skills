# Messages to the expert

Fill every `<…>`. Keep each message short enough to answer between other work.

## Asking for time

```text
Hi <name>, I'm documenting <the feature or change> for <the readers>, publishing <date>.

I've read <the change, the issue, the tests> and drafted <an outline · a first draft> (<link>). Could I have <30> minutes, <a call · a screen-share while you do the task>, before <date>, to check <the one or two things the draft can't settle>?

If time is short, I can send a short written list instead.
```

## A written question list

```text
Hi <name>, draft attached: "<page title>". <N> questions block publishing; the rest can wait.

Blocking:
1. <Question, answerable in a sentence, with the value you need.>
2. <Question.>

Nice to have:
3. <Question.>

It publishes <date>; if I haven't heard by <date>, <the point> goes in marked "unverified".
```

## Asking for a technical review

```text
Hi <name>, could you check <page title> (<link>) for technical accuracy only, by <date>? I'm not asking about wording.

I've flagged <N> places inline:
1. <Section>: <the claim> — is this still true in <version>?
2. <Section>: <the claim> — where is this value defined?

It publishes <date>; anything unconfirmed by then ships marked "unverified".
```
