# Contributor guidelines and the guest brief

Two documents you send someone who writes for your publication — a swap partner or a guest. The guidelines are one per publication and change rarely; keep them as a page on the site or a file beside `profile.md`. The brief is one per piece, sent with an accepted pitch or a swap, and filled from the topic's `brief.md`. Copy each block, keep every field, and leave a field blank until it's known. Take the voice, length and formatting rules from `writing-guide.md`; never restate the whole guide, only what a guest needs.

## Contributor guidelines

```markdown
# Write for <publication>

<One line: who reads it and what they come for.>

## What we publish

| Field              | Answer                                                         |
| ------------------ | -------------------------------------------------------------- |
| Readers            | who they are and what they already know                        |
| Pieces we take     | tutorials · guides · essays · case studies…                    |
| Pieces we don't    | product announcements, pieces published elsewhere, …           |
| Length             | words                                                          |
| Voice              | person (I / we / you), register — from the writing guide       |
| Format             | Markdown or a shared doc; headings, code, images               |
| Images             | who provides them, sizes, alt text required                    |
| Originality        | unpublished anywhere else; AI use and how it's disclosed       |
| Paid               | unpaid · a fee per piece (amount, when it's paid)              |
| Rights             | first publication; exclusive for a period; republishing after  |
| Byline and bio     | the bio's length, the links allowed, headshot size             |
| Links              | how many links to the author's own work; followed or not       |
| Sponsored content  | never in a guest piece; or only on our terms, labelled         |

## How to pitch

| Field                 | Answer                                                   |
| --------------------- | -------------------------------------------------------- |
| Send to               | address or form                                          |
| Include               | the idea, why our readers, why you, an outline, clips    |
| Send the draft or not | outline first, never a finished piece unless asked       |
| Response time         | days; no reply after it means no                         |

## After we accept

| Field          | Answer                                                  |
| -------------- | ------------------------------------------------------- |
| The brief      | angle, length, draft date, sent with the acceptance     |
| Edits          | how many rounds; you see the final edit and the title    |
| Publish date   | set by us, confirmed with you                           |
| Sharing        | what we ask: share it once on your channels             |
```

## Guest brief

```markdown
# Brief for <guest's name> — <working title>

| Field             | Answer                                                     |
| ----------------- | ---------------------------------------------------------- |
| Publication       | name and link                                              |
| Format            | blog post · newsletter issue                               |
| Reader            | who it's for, and the question in their words              |
| Angle             | what this piece adds that ours don't                       |
| Outline           | as agreed                                                  |
| Length            | words                                                      |
| Draft due         | date                                                       |
| Edit rounds       | number, and when you'll see the final edit and the title    |
| Publish date      | date                                                       |
| Byline and bio    | bio length, links allowed, headshot                        |
| Links back        | where to your work, and from ours to yours (a swap)        |
| Fee               | amount and when it's paid, or unpaid                       |
| Rights            | first publication; exclusive until; then republish with a link to the original |
| Our guidelines    | link                                                       |
| Contact           | name and address                                           |
```
