# Pitch log

The template for `pitch-log.md`, kept at the root of the publications folder beside the publications themselves, one log for every outlet (in a chat app, a file in the project with the same name). Copy the block below; keep every column and leave a cell empty until it's known. Add a row for each pitch, and a row in Commissions when one is accepted; change only your own rows.

Status is one of `sent` · `followed up` · `accepted` · `declined` · `no answer` · `withdrawn`.

```markdown
# Pitch log

## Pitches

| Date | Outlet | Editor | Pitch | Status | Follow-up date | Outcome |
| ---- | ------ | ------ | ----- | ------ | -------------- | ------- |
|      |        |        |       |        |                |         |

## Commissions

One row per accepted pitch, from the terms agreed in writing.

| Outlet | Topic folder | Fee | Paid on | Rights granted | Exclusivity ends | Deadline | Published URL | Invoiced | Paid |
| ------ | ------------ | --- | ------- | -------------- | ---------------- | -------- | ------------- | -------- | ---- |
|        |              |     |         |                |                  |          |               |          |      |
```

- **Date** — the day the pitch was sent, `yyyy-mm-dd`.
- **Pitch** — the proposed title, or the idea in a few words.
- **Follow-up date** — the outlet's stated response time after the send date, or about two weeks if none is stated (common practice).
- **Outcome** — accepted with the fee, declined with any reason given, or re-pitched elsewhere and where.
- **Topic folder** — `<outlet publication>/topics/<yyyy-mm>-<slug>`, the commissioned piece's folder under the outlet's publication folder.
- **Paid on** — acceptance or publication.
- **Exclusivity ends** — the date the piece may be republished, from the rights granted.
