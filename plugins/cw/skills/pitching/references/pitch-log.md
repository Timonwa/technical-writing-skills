# Pitch log

The template for `pitch-log.md`, kept at the root of the publications folder beside the publications themselves, one log for every pitch and proposal — sent and received, every kind, sponsors included (in a chat app, a file in the project with the same name). Copy the block below; keep every column and leave a cell empty until it's known. Add a row for each pitch or proposal, and a row in **Agreements** when one is accepted; change only your own rows.

```markdown
# Pitch log

## Pitches and proposals

| Date | Direction | Kind | Partner | Contact | Pitch | Status | Follow-up date | Outcome |
| ---- | --------- | ---- | ------- | ------- | ----- | ------ | -------------- | ------- |
|      |           |      |         |         |       |        |                |         |

## Agreements

One row per accepted pitch or proposal, from the terms agreed in writing.

| Kind | Partner | Topic folder | Money | Paid on | Rights | Exclusivity ends | Deadline | Published URL | Invoiced | Paid |
| ---- | ------- | ------------ | ----- | ------- | ------ | ---------------- | -------- | ------------- | -------- | ---- |
|      |         |              |       |         |        |                  |          |               |          |      |
```

- **Date** — the day it was sent or received, `yyyy-mm-dd`.
- **Direction** — `sent` · `received`.
- **Kind** — `writing for them` · `swap` · `co-written` · `guest on ours` · `sponsored`, the same words as the brief's **Collaboration** field.
- **Partner** — the outlet, the swap partner, the co-author, the guest or the brand.
- **Contact** — the editor or person the email went to or came from.
- **Pitch** — the proposed title, the idea in a few words, or the slot a sponsor would buy.
- **Status** — `open` · `followed up` · `accepted` · `asked to revise` · `declined` · `no answer` · `withdrawn`.
- **Follow-up date** — for a sent pitch, the partner's stated response time after the send date, or about two weeks if none is stated (common practice); for a received one, the date you'll reply by.
- **Outcome** — accepted with the terms, declined with any reason given, or re-pitched elsewhere and where.
- **Topic folder** — for writing for them, `<outlet publication>/topics/<yyyy-mm>-<slug>`, under the outlet's publication folder; for every other kind, `<your publication>/topics/<yyyy-mm>-<slug>` (a swap has two, one per piece).
- **Money** — the fee you're paid, the fee you pay a guest, the sponsor's price, or `none`, with the currency.
- **Paid on** — acceptance, publication, before it runs, or invoice.
- **Rights** — the rights granted or asked for, and for a swap or co-written piece the links back agreed.
- **Exclusivity ends** — the date the piece may be republished, from the rights granted.
