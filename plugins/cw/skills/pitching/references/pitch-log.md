# Pitch log

The template for `pitch-log.md`, kept at the root of the publications folder beside the publications themselves, one log for every pitch and proposal — sent and received, every kind, sponsors included (in a chat app, a file in the project with the same name). Copy the block below; keep every column and leave a cell empty until it's known. Add a row for each pitch or proposal and update it as the thread moves; change only your own rows.

```markdown
# Pitch log

| Date | Direction | Kind | Partner | Contact | Pitch | Status | Follow-up date | Topic folder |
| ---- | --------- | ---- | ------- | ------- | ----- | ------ | -------------- | ------------ |
|      |           |      |         |         |       |        |                |              |
```

- **Date** — the day it was sent or received, `yyyy-mm-dd`.
- **Direction** — `sent` · `received`.
- **Kind** — `writing for them` · `swap` · `co-written` · `guest on ours` · `sponsored`, the same words as the brief's **Collaboration** field.
- **Partner** — the outlet, the swap partner, the co-author, the guest or the brand.
- **Contact** — the person the email went to or came from, and their address.
- **Pitch** — the proposed title, the idea in a few words, or where a sponsor would appear.
- **Status** — `open` · `followed up` · `asked to revise` · `accepted` · `confirmed` · `declined` · `no answer` · `withdrawn`.
- **Follow-up date** — for a sent pitch, the partner's stated response time after the send date, or about two weeks if none is stated (common practice); for a received one, the date you'll reply by.
- **Topic folder** — for writing for them, `<outlet publication>/topics/<yyyy-mm>-<slug>`, under the outlet's publication folder; for every other kind, `<your publication>/topics/<yyyy-mm>-<slug>` (a swap has two, one per piece).
