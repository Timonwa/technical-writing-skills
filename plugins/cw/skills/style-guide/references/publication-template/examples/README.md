# Examples

The pieces and images that show the publication at its best, so a skill can match them instead of describing them from memory.

What belongs here:

- **Sample covers** — three or four that follow the cover template in [brand.md](../brand.md), including one without a photo.
- **Logo files** — the versions `brand.md` lists, named for what they are: `logo-full-colour.svg`, `logo-reversed.png`.
- **Two or three pieces that best show the voice** — the published text, or a link to it.

Give each file one line in the list below saying why it's here and what it's typical of. Name the atypical ones too: a terse setup post, a guest piece or a one-off format teaches the wrong voice if it's mistaken for the norm.

| File | Why it's here | Typical?             |
| ---- | ------------- | -------------------- |
|      |               | _yes · no — and why_ |

In a chat app, upload these files to the project's files beside `profile.md`, `writing-guide.md` and `brand.md`, and keep this list with them.
