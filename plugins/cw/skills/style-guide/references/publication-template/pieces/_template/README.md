# A piece's folder

One folder per piece, named `<yyyy-mm>-<slug>` (for example `2026-12-rates-explainer`), under the publication's `pieces/`. Copy this folder to start one; never edit the template itself.

| File or folder | What goes in it                                                    |
| -------------- | ------------------------------------------------------------------ |
| `brief.md`     | status, who's on it, the publish date, and the brief               |
| `draft.md`     | the draft, or a link to it in the platform                         |
| `sources.md`   | the source log: one line per claim and where it came from          |
| `interviews/`  | notes and transcripts, with each person's consent recorded         |
| `images/`      | the cover, the share card and the diagrams                         |
| `social.md`    | the posts for each platform                                        |
| `copies.md`    | where it's cross-posted: platform, URL, date, canonical or noindex |
| `reports/`     | `review.md`, `ai-check.md`, `seo.md`                               |

In a chat app, a project's files can't hold folders, so each file takes the piece's folder name as a prefix: `2026-12-rates-explainer--brief.md`, `2026-12-rates-explainer--sources.md`.
