# Blogging platforms: what each copy sets

Verify before relying on these — platforms move their settings. Every number links its source; "secondary" marks a number from a non-official source because no official one was found, and "not confirmed" marks what no live source states. These fill each platform's section of `copies.md`.

A platform's title field takes `blog.md`'s `title`, and its subtitle, description or meta description field takes `blog.md`'s `description` — trimmed to the platform's cap where it has one. The opening excerpt is a different thing and never goes in those fields.
