# Platform limits and counting rules

Verify before relying on these — something in these tables changes every few months. Every number links its source; "secondary" marks a number from a non-official source because no official one was found, and "not confirmed" marks what no live source states. A number marked "(common practice)" is a working habit, not a platform rule.

## Hashtags, mentions and links

- **X:** hashtags count as ordinary characters, and so do mentions you add; no cap on either found ([counting characters](https://docs.x.com/fundamentals/counting-characters)).
- **Threads:** one topic tag per post, 1–50 characters, and at most 5 links ([Threads posts API](https://developers.facebook.com/docs/threads/posts)).
- **Bluesky:** up to 8 tags in a post record's `tags` field, each up to 64 graphemes ([post lexicon](https://github.com/bluesky-social/bsky/blob/main/lexicons/app/bsky/feed/post.json)).
- **Instagram:** 5 hashtags per post and Reel since December 2025, from Instagram's head's announcement as reported (secondary: [Digital Trends](https://www.digitaltrends.com/social-media/instagram-now-limits-you-to-five-hashtags-per-post/)); the API reference still says 30 hashtags and 20 @ tags ([IG User Media API](https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media)). Write to 5.
- **TikTok:** hashtags and mentions count toward the caption; no cap found ([direct post API](https://developers.tiktok.com/doc/content-posting-api-reference-direct-post)).
- **Everywhere else:** no cap found.

## Working length and idiom

Common practice, not platform rules: what keeps a post readable before the fold.

| Platform          | Working length                                 | Idiom                                       |
| ----------------- | ---------------------------------------------- | ------------------------------------------- |
| X                 | about 70–100 characters for a standalone post  | punchy, hook-first                          |
| Bluesky           | well under the limit                           | conversational, community                   |
| Threads           | a few sentences                                | casual, personal                            |
| Mastodon          | a few sentences                                | earnest, community-oriented                 |
| LinkedIn posts    | the hook in the first 140; 1,000–2,000 in all  | narrative                                   |
| Facebook          | short — under about 80 characters for a link   | conversational, community                   |
| Instagram         | the point before the cut-off                   | visual-first; the image carries it          |
| Pinterest         | title front-loaded; a keyword-rich description | search-first; the image is the post         |
| TikTok            | the hook in the first line                     | hook in the first seconds; caption supports |
| YouTube posts     | a few sentences                                | an update to the channel's subscribers      |
| Substack Notes    | a few sentences                                | conversational, among writers and readers   |
| WhatsApp Channels | a few lines                                    | one-way updates, read like a message        |
