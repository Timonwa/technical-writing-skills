# Interview notes

The notes file for one interview, saved as `interviews/<yyyy-mm-dd>-<name>.md` in the topic's folder (`interviews/2026-12-03-ada-okafor.md`), the date being the day of the interview and the name the person's, in lowercase with hyphens. In a chat app, the file is `<topic folder>--interview-<yyyy-mm-dd>-<name>.md`. Copy the block below; keep every field and leave a cell empty until it's known. A case study adds the fields in [case-study.md](case-study.md#before-publishing) under the consent table.

```markdown
# Interview — <person's name>

| Field                 | Answer                                                                                  |
| --------------------- | --------------------------------------------------------------------------------------- |
| Person                |                                                                                         |
| Who they are          | expert · customer · lived experience · founder · community member or guest · creator    |
| Role                  | title and organisation, or how they're connected, as it will appear in the piece        |
| Verified by           | how the identity and the standing the piece leans on were confirmed                     |
| Conflicts of interest | who pays them, what they sell, what they gain, anything given for taking part — or none |
| Becomes               | quotes in a piece · Q&A article · profile or feature · case study · testimonial         |
| Date                  | yyyy-mm-dd                                                                              |
| Format                | call · video · in person · email                                                        |
| Topic                 | the topic folder                                                                        |

## Consent

Agreed before the interview started, in plain words. The last row is for a Q&A article, a case study or a testimonial.

| Use                               | Agreed | How and when it was agreed |
| --------------------------------- | ------ | -------------------------- |
| Name                              |        |                            |
| Quote                             |        |                            |
| Recording                         |        |                            |
| The version that runs, sent whole |        |                            |

- **Identified as:** name, role and organisation, or how they're described without a name.
- **Off the record or not for publication:** what, if anything, and what it means here.
- **Embargo:** the date and time, or none.
- **Sees a draft or approves quotes:** what the publication's policy and the output allow, and what was said.
```
